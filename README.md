# Мировое время

Небольшой веб-сервис, который переводит время из одного часового пояса в другой и показывает расписание международных встреч. Сделан как учебный проект, чтобы показать, что три сервиса (фронт, бэк и база) нормально поднимаются вместе через docker-compose.

## Что внутри

Три контейнера:

| Сервис      | На чём сделан                         | Порт |
| ----------- | ------------------------------------- | ---- |
| Фронтенд    | Astro (серверный режим, Node-адаптер) | 4321 |
| Бэкенд      | Node.js, Express, `pg`, `date-fns-tz` | 3000 |
| База данных | PostgreSQL 16                         | 5433 |

Порт БД наружу выставлен 5433. Внутри сети Docker бэкенд ходит в базу по имени сервиса `db` и порту 5432.

## Как это работает

Браузер разговаривает только с фронтендом. Запросы на `/api/...` Astro пересылает бэкенду, а тот читает данные из PostgreSQL:

```
браузер → frontend → backend → db
```

**Перевод времени.** Человек вводит дату, время и два пояса. Бэкенд превращает время в UTC, а потом показывает его в нужном поясе. Летнее время учитывается: например, 20 октября Лондон живёт по UTC+1, а 30 октября уже по UTC+0, и разница с Токио меняется на час.

**Расписание встреч.** Встречи лежат в таблице `meetings` в PostgreSQL (начало хранится в UTC). Когда пользователь выбирает свой пояс, бэкенд пересчитывает время каждой встречи и отдаёт готовый результат. Браузер сам ничего не считает, только выводит то, что пришло.

## Запуск

Нужен установленный Docker Desktop. В корне проекта рядом с `docker-compose.yml` нужно создать файл `.env` с следющими переменными:

POSTGRES_USER=tz_user
POSTGRES_PASSWORD=tz_pass
POSTGRES_DB=timezone_db

DB_PORT=5433
BACKEND_PORT=3000
FRONTEND_PORT=4321

Для запуска нужна одна команда:

```bash
docker compose up -d --build # сборка и запуск всех трех контейнеров сразу
```

Прочие команды:

```bash
docker compose up -d --build backend # сборка и запуск backend
docker compose up -d --build frontend # сборка и запуск frontend

docker compose stop # остановка контейнеров
docker compose down # остановка и удаление контейнеров
docker compose down -v # остановка и удаление контейнеров и данных БД
```

После этого:

- сайт: http://localhost:4321
- проверка бэкенда и базы: http://localhost:3000/api/health
- в pgAdmin: хост `localhost`, порт `5433`, база `timezone_db`, логин и пароль из `.env`

Остановить: `docker compose down`.

## API бэкенда

- `GET /api/health` проверяет, что бэкенд жив и видит базу
- `GET /api/convert?time=2026-10-20T09:00&from=Europe/London&to=Asia/Tokyo` переводит время
- `GET /api/meetings?tz=Asia/Tokyo` отдаёт встречи из БД, пересчитанные на нужный пояс
